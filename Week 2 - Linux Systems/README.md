# Linux Server Readiness Audit

## Project Description

This project is part of my AI/DevOps Engineering learning journey.

The goal is to practice Linux system administration by collecting and reviewing important system information using Ubuntu Linux (WSL2).

I created a system report to check users, groups, file permissions, running processes, installed packages, services, logs, environment variables, and SSH information.

## Skills and Commands Used

- **File Management:** `mkdir`, `touch`, `ls`, `cat`, `nano`
- **Users and Groups:** `whoami`, `id`
- **File Permissions:** `chmod`, `ls -l`
- **Process Management:** `ps`
- **Environment Variables:** `echo $HOME`, `echo $PATH`
- **Package Management:** `apt list --installed`, `apt show`
- **Service Management:** `systemctl`
- **Log Analysis:** `journalctl`, `grep`
- **SSH:** `ssh -V`
- **Output Redirection:** `>`, `>>`, `2>>`

## Project Files

- `system_report_example.txt` — An anonymized example of the Linux system audit report.
- `README.md` — Project documentation.

Note: The original system_report.txt is kept private
because it contains real system information.
## What I Learned

Through this project, I practiced inspecting a Linux system, checking permissions, monitoring running processes and services, searching logs, and saving command outputs into an organized report.

I also learned how to combine commands using pipes and redirect standard output and standard error into files.
